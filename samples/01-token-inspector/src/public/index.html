Token inspector

The infographic draws "Issue Token" as one icon. Here is what that icon actually produced for you: a specific set of claims, with a specific lifetime, most of which nobody ever looks at.

This page does not decode a Microsoft Graph token, on purpose

There is no Graph token anywhere in this app. Microsoft Graph access tokens use a proprietary format and Microsoft documents them as opaque to clients: they cannot be validated by the rules on this page and their contents are not a contract you may build on. Pasting one into jwt.ms is sanctioned for debugging and nothing else.

The same rule applies to every access token you did not issue. A client must treat an access token as an opaque string and must never validate it. Only the resource named in aud validates, and only tokens meant for itself. Validating somebody else token is the confused deputy problem with extra steps.

Which is why the access token panel below is filled in by the API, not by this page. The browser sends the token to /api/whoami and renders what the resource says about it. The ID token panel is different: an ID token is issued to this client, so this client is allowed to read it.

Lifetime

--:-- until exp
-- minutes granted (exp minus iat)

  • Entra ID randomizes the default access token lifetime between 60 and 90 minutes, 75 minutes on average. That is deliberate: if every token expired on a round number, every client on earth would refresh at the same instant and spike traffic to Entra ID. Sign in again tomorrow and this number will be different.
  • A tenant with no Conditional Access gets a 2 hour default for clients such as Teams and Microsoft 365.
  • Nothing can revoke this token before the countdown reaches zero. Disabling the account, deleting the session, revoking consent: none of it reaches a token already in browser memory. The client waits for expiry and then presents its refresh token.
  • In a continuous access evaluation session the picture inverts: the access token becomes long lived, 20 to 28 hours, because revocation moves to a signal from the resource instead of to expiry. Configurable Token Lifetime policy is not honored for CAE-aware sessions.
  • This app is registered with a spa redirect URI, so the refresh token behind that silent renewal lasts 24 hours, not the usual 90 days. Refresh tokens also rotate on every use, so the one held now is not the one issued at sign-in.
